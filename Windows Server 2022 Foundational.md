# Windows Server 2022 Fundamentals

## Overview
This repository documents my hands-on learning and practical experience with Windows Server 2022 administration in a virtualized lab environment. It covers core server roles, system configuration, identity services, networking, storage, and basic security hardening concepts used in enterprise environments.
